# Next Layer Group

Installers for **Next Layer Group**, Next Layer's team chat (built by [dev3lop](https://dev3lop.com), on Relay).

| | Download |
|---|---|
| **Mac** (Apple Silicon + Intel, macOS 12+) | [NextLayerGroup-mac.dmg](https://github.com/MassiveNoobie/nextlayer-group-releases/releases/latest/download/NextLayerGroup-mac.dmg) |
| **Windows** (10 and 11, 64-bit) | [NextLayerGroup-windows-setup.exe](https://github.com/MassiveNoobie/nextlayer-group-releases/releases/latest/download/NextLayerGroup-windows-setup.exe) |

You need an invite to the Next Layer workspace: open the invite link you were sent, join with GitHub, then sign in to the app with the same GitHub account.

**First open on a Mac:** open the .dmg and drag the app to Applications. If macOS blocks it, open **System Settings › Privacy & Security** and click **Open Anyway**.

**First run on Windows:** run the installer (no admin rights needed). If SmartScreen says "Windows protected your PC", click **More info › Run anyway**.

Checksums for each release are in its `SHA256SUMS.txt`.
